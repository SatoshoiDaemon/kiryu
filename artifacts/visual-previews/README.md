# Previews visuais

- `profile-classic.png`, `profile-wide.png`, `profile-portrait.png`, `profile-folio.png` e `profile-orbital.png` são exemplos PNG renderizados pelo `renderMemberCard` com layouts, molduras, avatares, barras, paletas e badges diferentes. O cartão fólio inclui arte de fundo local gerada pelo script.
- `profile-member.png` mantém uma prévia compatível com o cartão legado.
- `phase-2.3-interfaces.png` demonstra visualmente a central de armazenamento, editor de mensagens e ferramentas comunitárias. É um mockup conceitual, não uma captura do cliente Discord.
- `components-v2-fixtures.json` serializa builders Discord reais da loja, detalhe, inventário, Orbes, carteira, painel, armazenamento, editor, ajuda, enquete e sorteio. A renderização final dessas telas depende do cliente Discord.
- Gere novamente com `node scripts/render-visual-previews.js`.
