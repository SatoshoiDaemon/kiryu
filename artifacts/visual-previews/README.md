# Previews visuais

- `profile-classic.png`, `profile-wide.png`, `profile-portrait.png`, `profile-folio.png` e `profile-orbital.png` são exemplos PNG renderizados pelo `renderMemberCard` com layouts, molduras, avatares, barras, paletas e badges diferentes. O cartão fólio inclui arte de fundo local gerada pelo script.
- `profile-member.png` mantém uma prévia compatível com o cartão legado.
- `components-v2-fixtures.json` serializa builders V2 reais de loja, detalhe, inventário, Orbes, carteira e painel. A renderização dessas telas é feita pelo cliente Discord; não há captura do app Discord neste ambiente.
